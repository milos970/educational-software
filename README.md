## 📝 Description

Educational Software is a web application designed to support teaching in the **Numerical Methods** course.

The application allows users to work with selected numerical methods, enter input data, and visualize the results of individual calculations. The goal of the project is to connect theoretical knowledge of numerical methods with their practical implementation in an interactive web application.

---

## ✨ Features

* Implementation of selected numerical methods
* Interactive input of calculation parameters
* Visualization of calculation results
* User authentication
* Input validation
* Database persistence
* Server-side rendering with Thymeleaf
* Email communication

---

## 🏗️ Architecture

The application is built using a **Spring MVC** architecture:

```text
┌─────────────────────────────┐
│          Frontend           │
│ HTML / CSS / JavaScript     │
│        Thymeleaf            │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│       Controller Layer      │
│        Spring MVC           │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│        Service Layer        │
│       Business Logic        │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│       Repository Layer      │
│      Spring Data JPA        │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│        H2 Database          │
└─────────────────────────────┘
```
